## Reflection

**What design choices did you make (colors, fonts, layout)?**
I used Material Design 3 with simple spacing and clear text sizes. The layout is centered with proper padding.

**How did you ensure the screen is user-friendly and accessible?**
I made the button big enough to tap easily and used text sizes that adjust to user settings. Everything has good spacing and contrast.

**What would you improve if this were a real app?**
Add real profile pictures, make the edit button actually work, and save user data to a database.
