# ProfileUI - StudentName-Act03

Simple Android profile screen prototype demonstrating UI/UX principles.

## Design Choices

**Colors, Fonts, Layout:**

- Material Design 3 for consistent theming
- 8dp grid system (24dp padding, 16dp spacing)
- Clear typography hierarchy (headline for name, body for bio)

**Accessibility:**

- 48dp button height for touch targets
- sp units for text (scales with user preferences)
- Material 3 contrast ratios for readability
- Adequate spacing between elements

**Improvements for Real App:**

- Image loading library (Coil/Glide)
- Functional edit screen with validation
- Additional profile fields (email, phone, social)
- Data persistence (Room/API)
- Profile picture upload
- Dark mode support
